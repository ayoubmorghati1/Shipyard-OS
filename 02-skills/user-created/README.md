# User-Created Skills

Store reusable skills here.

Use this folder for skills that can support more than one Work System.

Examples:

```text
sales-call-analysis/
proposal-drafting/
meeting-summary/
follow-up-drafting/
research-briefing/
```

Each skill should have:

```text
SKILL.md
```

Keep skills modular, but useful. A skill can be a whole AI SOP.

Do not create a new skill for every tiny action.
