# Your Business

This is where your real Work System Packages go.

Copy:

```text
workspace/_template-work-system/
```

Into:

```text
workspace/your-business/{workflow-slug}/
```

Example:

```text
workspace/your-business/discovery-call-to-proposal/
```

If you want to organize by business function, use folders like:

```text
workspace/your-business/
|--- growth/
|--- delivery/
|--- knowledge/
|--- leadership/
|--- marketing/
`--- operations/
```

Then place workflow packages inside the relevant function.
