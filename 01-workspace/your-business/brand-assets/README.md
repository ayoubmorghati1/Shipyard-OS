# Brand Assets

Store source material the agent can use as reference.

Examples:

- logos
- screenshots
- pitch decks
- proposal examples
- case studies
- testimonials
- voice samples
- website copy
- product screenshots

Do not treat this folder as the system memory.

Use this rule:

```text
brand-assets = raw source material
business-context = interpreted business context
AGENTS.md = living agent brief
Work System Package = one workflow
```
