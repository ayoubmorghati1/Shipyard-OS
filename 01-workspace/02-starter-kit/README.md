# Starter Kit

This folder is only for starting and understanding Work Systems.

It is not where real client or business work should live.

## Contents

| Folder | Purpose | Use it when |
| --- | --- | --- |
| `template-work-system/` | Blank Work System Package | You are starting a new workflow |
| `example-work-system/` | Filled example package | You want to see what a finished v1 can look like |

## Where Real Work Goes

Real Work System Packages go here:

```text
01-workspace/01-your-business/{workflow-slug}/
```

## Rule

```text
Copy the template.
Learn from the example.
Build inside 01-your-business.
```
