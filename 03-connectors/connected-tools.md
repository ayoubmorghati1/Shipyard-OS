# Connected Tools

Use this file to record the tools, data sources, and apps the business can use inside Work Systems.

This file is global because the business has one tool environment.

Do not add tools for the sake of it. Add a tool only when it directly supports a workflow.

## How This Connects To A Work System

Use this global registry to know what exists.

Then, inside each Work System:

- `02-system-blueprint.md` names which connected tools the system uses.
- `live-system-records/live-interface.md` stores the actual links, folders, lists, docs, automations, or app locations.
