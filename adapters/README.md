# Platform Adapters

Shipyard-OS is platform-agnostic.

Use this folder only when you need notes for a specific live interface.

Examples:

```text
adapters/claude.md
adapters/chatgpt.md
adapters/gemini.md
adapters/codex.md
adapters/clickup.md
```

Do not start here.

Start in `workspace/`, build the Work System Package, then choose the platform that fits the team's real work habits.
