# Shipyard Work System Framework

Shipyard helps businesses turn important workflows into AI-assisted Work Systems.

The core belief:

> AI becomes valuable when it improves real work.

The unit of value is the workflow.

---

## Method

```text
Map -> Build -> Run
```

## Anatomy

Every Work System has:

```text
Workflow
Context
Skills
Interface
Control
Feedback
```

## Memory

Memory is not a separate top-level component.

```text
Context contains the Memory Base.
Feedback updates the Memory Base.
```

## Skill

A Skill is a reusable AI SOP that helps perform a specific part of a workflow.

## Learning Loop

```text
Use the workflow
-> review the output
-> capture what worked or failed
-> update memory, context, skills, controls, or workflow steps
-> run it better next time
```

Simple rule:

> Feedback creates learning. Control approves learning. Memory stores learning. The system gets better.
