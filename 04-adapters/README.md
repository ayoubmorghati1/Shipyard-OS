# Platform Adapters

Shipyard-OS is platform-agnostic.

Use this folder only when you need notes for a specific live interface.

Examples:

```text
04-adapters/claude.md
04-adapters/chatgpt.md
04-adapters/gemini.md
04-adapters/codex.md
04-adapters/clickup.md
```

Do not start here.

Start in `01-workspace/`, build the Work System Package, then choose the platform that fits the team's real work habits.
